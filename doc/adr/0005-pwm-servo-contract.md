# 0005: PWM サーボの角度変換と初期状態

- ステータス: Accepted

## 背景

汎用 RC サーボをボードに依存せず制御する必要がある。
仕様は最小・最大間の線形角度変換と、校正用の中央パルスを定義している。
ドライバには機構固有の安全角が分からない。

## 決定

- サーボクラスの公開 API と PWM 実装を分け、1 Devicetree node を 1 device にする。
- 角度は最小・最大パルスの間で線形変換し、整数 us に四捨五入する。
  `center-pulse-us` は範囲を検証した校正参照値で、必要なら直接指定 API で出力する。
- 初期化時は PWM の停止を要求する。中央角への移動はアプリケーションが明示的に指示する。
- 停止には設定周期を保ったパルス幅 0 を使用し、共有 PWM slice の周期変更を避ける。
- API は supervisor mode 向けの vtable dispatch とする。userspace syscall は対象外とする。

## 却下した案と帰結

中央パルスを第 3 点とした区分線形補間は、指定された変換式と異なるため採用しない。
非対称なサーボの中央位置の校正はパルス直接指定で行える。
起動時の中央移動や停止時の安全角復帰は、機構により危険な方向が変わるため実装しない。
停止は電源断ではなく、サーボの保持動作は製品の仕様に従う。
